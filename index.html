💡 一句话

不知道该养一只龙虾还是建一个龙虾生态？
像伙伴一样跟你聊两句 → 推荐架构 + 分工表 + SkillHunt Skill 清单 → 你直接装，生态就搭起来了。

🤝 两个核心问题

问题1：你想让你的龙虾做什么？

做一件事 → 一只龙虾就够了
做一系列事 → 需要龙虾生态
做不同领域的事 → 需要专业分工

⭐ 问题2：你想拥有什么样的合作伙伴？（核心）

这才是关键——不是选架构模式，是选合作伙伴：

搭档类型什么时候需要例子
全能型搭档简单任务"查数据+画图表" → 1 Agent + 5 Tools
几个专业搭档不同领域各擅一门数据搭档 + 设计搭档 + 安全搭档
审批型搭档做错后果严重执行→审批检查→才交付
探索型搭档可试错、追求创意各自探索→汇总最好的发现

⚠️ 自省：什么时候一只龙虾就够了？

任务只有1步、不涉及多个领域、1个Prompt+几个Tools就能搞定 → 别建生态，养一只龙虾就够了。
如果评估后所有维度都指向单体，我会主动告诉你：「省下建生态的复杂度，直接干活。」
